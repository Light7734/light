Light Engine
===================================================================================================

Current Development Pipeline
---------------------------

Supported Features
---------------------------
- Macro-free testing framework
- Very basic ECS
- Asset baking with support for:
    - glsl
    - obj
- Native Wayland
- Basic stuff like maths, timer, input

Planned Features
---------------------------
- Vulkan Renderer (1.4+) with support for:
    - Culling
    - LoDing
    - Physically based rendering (PBR)
    - Sky spheres
    - Mesh shaders
    - Bloom
    - Screen Space Ambient Occlusion (SSAO)
    - Simple Anti-aliasing
    - Gamma correction
    - Render graphs
- Mocking for the testing framework
- GUI Library (most likely immediate mode)
- Slang
- Asset baking support for:
    - ktx
    - gltf
    - png
    - jpg
    - txt
- Lua scripting support
- Editor
